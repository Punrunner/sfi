บทที่ 10 · Prompt พร้อมคัดลอก

Storytelling for Influence · อ.ไชยยศ ปั้นสกุลไชย

กด คัดลอก แล้ววางในช่องพิมพ์ของ ChatGPT
ข้อความใน [ ] คือส่วนที่ท่านเปลี่ยนเป็นข้อมูลของท่านเอง (ตัวอย่างในหนังสือเป็นข้อมูลของคุณมายด์)

Prompt 1 : ร่างโครงเรื่องตามแบบที่เลือก(ขั้นที่ 4)

คุณเป็นโค้ชด้านการเล่าเรื่องเพื่อโน้มน้าวใจ
ช่วยร่างโครงเรื่องให้ครบทุกแบบที่ฉันเลือก (แยกกันแบบละชุด) จากข้อมูลของฉันด้านล่าง
แบบที่เลือก: [1) Before → Turning Point → After 2) Failure → Lesson 3) "ลองนึกภาพว่า..."]
ทุกแบบวางตามเส้นทาง 5 ป้าย: Hook → Before → Turning Point → After → Ask
แต่ละป้ายเขียน 1–2 ประโยค
ใช้เฉพาะข้อเท็จจริงที่ฉันให้ ห้ามแต่งตัวเลขหรือเหตุการณ์เพิ่ม ถ้าข้อมูลไม่พอให้เขียนว่า "ต้องถามเพิ่ม"

ข้อมูลของฉัน
ผู้ฟัง: [คุณวิชัย เจ้าของร้านขายของชำ มีตู้แช่เปิดทั้งวัน 3 ตู้]
เขาเชื่อว่า: [โซลาร์แพง ไม่คุ้ม และติดแล้วหลังคาจะรั่ว]
แรงต้าน: [ไม่เชื่อว่าติดแล้วหลังคาจะไม่รั่ว ไม่เชื่อว่าคุ้มจริง]
การกระทำที่ต้องการ: [ให้ช่างขึ้นดูหลังคาฟรี 30 นาที วันเสาร์นี้]
เวลา/โอกาส: [3 นาที คุยกันที่ร้าน]
เรื่องที่เลือกไว้: [ป้าศรี ร้านข้าวแกง ลูกค้าเก่า เคยกลัวหลังคารั่ว ลังเลเกือบปี หลังพายุขึ้นไปดูใต้หลังคาบ้านข้าง ๆ ที่ติดแผงแล้ว ไม่รั่ว จึงติด ตอนนี้ค่าไฟลดลงเกือบครึ่ง]

Prompt 2 : เปรียบเทียบเป็นตาราง(ขั้นที่ 7)

ช่วยเปรียบเทียบโครงเรื่องทุกแบบด้านบนเป็นตาราง
คอลัมน์: แบบ | จุดแข็ง | จุดอ่อน | ตอบแรงต้าน [ไม่เชื่อว่าหลังคาจะไม่รั่ว ไม่เชื่อว่าคุ้ม] ได้ดีแค่ไหน (1–5) | เหมาะกับเวลา [3 นาที] ไหม
ใต้ตาราง แนะนำว่าควรเลือกแบบไหน เพราะอะไร ไม่เกิน 3 บรรทัด

Prompt 3 : ให้ AI ถามเราก่อน(ขั้นที่ 9)

ฉันเลือกแบบ [Before → Turning Point → After]
ก่อนปรับ ช่วยถามคำถามฉัน 3 ข้อ เพื่อให้ป้าย Before, Turning Point และ After มีฉากและรายละเอียดจริง
ถามเป็นข้อ ๆ เท่านั้น ยังไม่ต้องเขียนเรื่องใหม่

Prompt 4 : ตอบคำถาม แล้วให้เขียนใหม่(ขั้นที่ 11)

คำตอบของฉัน:
- [ป้าศรีเคยพูดว่า "ป้ากลัวเจาะหลังคาแล้วน้ำหยดใส่หม้อแกง"]
- [เช้าหลังพายุเข้าทั้งคืน ป้าปีนบันไดขึ้นไปดูใต้หลังคาบ้านข้าง ๆ เห็นว่าแห้งสนิท บ่ายนั้นถือบิลค่าไฟ 12 เดือนมาที่ร้าน]
- [ทุกวันนี้ป้าถ่ายรูปบิลส่งไลน์มาทุกเดือน ใบรับประกันแปะไว้ข้างตู้เย็น]

ช่วยเขียนโครงเรื่องแบบ [Before → Turning Point → After] ใหม่ด้วยคำตอบของฉัน
- ความยาว [3 นาที] แบ่งหัวข้อตาม 5 ป้าย พร้อมเวลาโดยประมาณของแต่ละป้ายเป็นวินาที
- ใส่ Key Message 1 ประโยคก่อนป้าย Ask
- ห้ามเพิ่มข้อเท็จจริงที่ฉันไม่ได้ให้
หน้านี้ไม่มีโฆษณาและไม่เก็บข้อมูลผู้ใช้
