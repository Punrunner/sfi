บทที่ 6 · Prompt พร้อมคัดลอก

Storytelling for Influence · อ.ไชยยศ ปั้นสกุลไชย

กด คัดลอก แล้ววางในช่องพิมพ์ของ ChatGPT
ข้อความใน [ ] คือส่วนที่ท่านเปลี่ยนเป็นข้อมูลของท่านเอง (ตัวอย่างในหนังสือเป็นข้อมูลของเกด)

Prompt 1 : ตรวจเรื่องของฉัน (EMOTION · โครงเรื่อง · จุดเปลี่ยน)

คุณเป็นโค้ชด้านการเล่าเรื่องเพื่อโน้มน้าวใจ ช่วยตรวจเรื่องของฉันด้านล่าง ยังไม่ต้องเขียนใหม่
คนฟัง: [แม่ของฉัน อายุ 62 ให้ค่ากับงานประจำที่มั่นคง]
แรงต้านของคนฟัง: [กลัวว่าลาออกแล้วจะไม่มีรายได้]
เรื่องของฉัน: [วางเรื่องที่ร่างไว้ หรือเคยเล่าแล้ว ตรงนี้]
เรื่องจริงที่ฉันมี (ถ้ามี): [เหตุการณ์จริงอื่นที่อาจใช้แทนได้]

ตอบ 3 ข้อ
1) EMOTION 7 ข้อ (Events, Main Characters, Oppositeness, Turning Points, Imagination, One Key Message, Neat Ending) ข้อไหนมีแล้ว ยกประโยคจากเรื่องมาให้ดู ข้อไหนยังขาด
2) ตอนนี้เรื่องเดินตามโครงเรื่องแบบไหน: Before → Turning Point → After / Problem → Solution / Why → What → How / Failure → Lesson / "ลองนึกภาพว่า..."
3) จุดเปลี่ยนตอบแรงต้านของคนฟังไหม ถ้ายังไม่ตอบ เรื่องจริงข้อไหนที่ฉันมีอาจตอบได้ดีกว่า
ห้ามแต่งตัวเลขหรือเหตุการณ์ขึ้นเอง ถ้าข้อมูลไม่พอให้เขียนว่า "ต้องถามเพิ่ม"
หน้านี้ไม่มีโฆษณาและไม่เก็บข้อมูลผู้ใช้
