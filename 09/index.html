บทที่ 9 · Prompt สำหรับหนังสือ

คัดลอก Prompt ทีละชุดตามขั้นตอนในหนังสือ แก้ข้อมูลใน [ ] ให้ตรงกับเรื่องของท่านก่อนส่ง

Prompt 1

ช่วยเป็นผู้ถามเพื่อให้ฉันค้นเรื่องของตัวเอง ไม่ใช่ผู้แต่งเรื่อง
ผู้ฟัง: [หัวหน้าฝ่าย]
เขาเชื่อว่า: [ระบบเดิมก็ดีอยู่แล้ว — ใบเบิกวัสดุแบบกระดาษ]
แรงต้าน: [นึกภาพไม่ออก / เรื่องใหม่มาก]
การกระทำที่ต้องการ: [ขอทดลองกับงานเดียว 1 เดือน ถ้าไม่ดีขึ้น เรากลับไปใช้กระดาษ]
เวลา/โอกาส: [ประชุมทีมประจำเดือน 3 นาที ในตัวอย่างสมมติ ยังไม่ใช่การอนุญาตให้ทดลอง]
เรื่องที่เลือกจาก T3: [A คืนสิ้นเดือนของหัวหน้า]
สิ่งที่รู้จาก T2: [ค่ำแล้ว หัวหน้ารวมแฟ้มสีฟ้า 3 แฟ้ม มีเสียงเครื่องคิดเลข]
สิ่งที่ยังไม่รู้: [ใช้เวลากี่ชั่วโมง และแบบออนไลน์จะช่วยงานนี้ได้จริงหรือไม่]
ถามทีละข้อ ถามแบบเปิด ห้ามเติมรายละเอียดเอง ไม่ชี้นำอารมณ์ คำพูด หรือผลลัพธ์
ตอนนี้ถามหนึ่งคำถามเกี่ยวกับสิ่งที่ฉันเห็นหรือได้ยิน แล้วรอคำตอบ
ถ้าฉันจำไม่ได้ ให้เก็บว่าจำไม่ได้ ไม่คาดคั้นและไม่เสนอฉากให้เลือก
อย่าแต่งประสบการณ์ของฉันหรือของ AI อย่าเดาเวลาที่ประหยัดได้

Prompt 2

คำตอบจากข้อมูล T2 ของฉัน: [ในตัวอย่างสมมติ ฉันเห็นแฟ้มสีฟ้า 3 แฟ้มบนโต๊ะ ได้ยินเสียงเครื่องคิดเลข หัวหน้าพูดว่า ไปก่อนเลย เดี๋ยวพี่ปิดไฟเอง]
สิ่งที่ไม่รู้: [กี่ทุ่ม ใช้เวลากี่ชั่วโมง และความคิดจริงของหัวหน้า]
ถ้าข้อมูลนี้ไม่ตอบคำถามที่เพิ่งถาม ให้ระบุว่าข้อมูลไม่พอ อย่าเติมแทน
หยุดถามก่อน แล้วสรุปเฉพาะข้อมูลที่ฉันให้เป็น 3 ช่อง: เห็นหรือได้ยินเอง / ยังไม่ทราบหรือจำไม่ได้ / ต้องตรวจหรือถามใคร
ข้อความใดเป็นเพียงการเดามุมหัวหน้า ให้แยกเป็นข้อเดา ไม่ใส่อัญประกาศเป็นคำพูดจริง
อย่าเปลี่ยนเรื่องที่เลือก A และอย่าเพิ่มผลประหยัด ผลทดลอง หรือการอนุญาตที่ยังไม่มี
หน้านี้ไม่มีโฆษณาและไม่เก็บข้อมูลผู้ใช้
